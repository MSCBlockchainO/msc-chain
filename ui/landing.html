What is MSC Chain?

Explore on-chain data

MSC Explorer provides a direct view of blocks, transactions, validator participation, finality, token supply, governance, and network health. Each explorer page reads public chain data and links related records so users can independently verify activity.

Use a self-custody wallet

MSC Wallet supports account creation, receiving, sending, transaction history, staking workflows, and testnet faucet access. Wallet secrets remain under the user's control, and security guidance is available before sensitive actions.

Frequently Asked Questions

MSC Chain FAQ

What is MSC Chain?

MSC Chain is a Layer-1 blockchain network with its own validator consensus, native MSC coin, explorer, wallet, governance system, and developer interfaces.

Where can I verify MSC transactions?

Open the official MSC Explorer and search by block height, transaction identifier, address, validator, or proposal. Explorer records link to related chain evidence and live network context.

How do I create an MSC wallet?

Use the official wallet, choose Create Wallet, and keep the recovery phrase offline. MSC support will never ask for your seed phrase or private key.

Can I run an MSC node or validator?

Yes. The documentation includes full-node and validator setup, hardware guidance, peer configuration, key security, monitoring, upgrades, and recovery procedures.

How do developers access MSC Chain?

Developers can use public REST and JSON-RPC endpoints, explorer APIs, and WebSocket events. Start with the RPC API and DApp development guides.
